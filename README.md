# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that combines several useful tools into one menu-driven application.

The toolkit contains three tools:

1. **To-Do List** - Allows users to add, view, and remove tasks.
2. **Simple Calculator** - Performs addition, subtraction, multiplication, and division.
3. **Number Guessing Game** - Challenges the user to guess a randomly selected number.

## Concepts Used

This project demonstrates:

- Variables
- User input
- If, elif, and else statements
- While loops
- For loops
- Lists
- Functions
- F-strings
- Random numbers
- Error handling
